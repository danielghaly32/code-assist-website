2. CSS code understanding and tags

Basics:

When typing CSS, it is the exact same as HTML, it needs an opening and a closing tag: <...> your text </...>
Although CSS have different tags. Like shown in this table demonstrating opening and closing tags.

Opening Command Your text Closing Command
<...> ... </...>
<style> Your Style of text </style>

CSS is all about telling the browser which text or area of the website to design. Now we will look at the different tags of CSS, like we did above with HTML.

Everything that will change color goes inside the style tags.

Tags inside <style> </style>


To change color of text

chosen text of website (h1, body, p) {

color: the color of your choice;

}

Example:

Lets say I want to make this Heading blue:

This is a blue heading

h1 {

color: blue;

}

But you're probabaly wondering how only this heading changed to the color blue. There are others of the same heading on the website, and none of them changed to blue.

To make only one of the chosen texts a certain color

Give the text an id:

<h1 id= “blue-heading”> This is a blue heading </h1>

Put the id name in # and use the same rules to give it the blue color:


#blue-heading {

color: blue;

}

To change background color of an area

body {

background-color: the color of your choice;

}

When we want to change the background color, we usually tell the browser to color everything in the body tags, and give it a certain color.

Now you can see, that the whole background is blue! This happened because I told the browswer to make a blue background from the body tags.

Now, You were probably wondering, can we also choose just one text or area of the website to give a background color? Yes! We can. This makes the website much more aesthetic.

Lets say I want to make just the background of this heading pink:

This is a pink heading!

Give the text an id:

<h2 id= “pink-heading”> This is a pink heading! </h2>

Put the id name in # and use the same rules to give it the pink color:


#pink-heading {

background-color: pink;

}

Classes

In CSS classes are used to give a certain area in the website a certain color. It is very similar to id=" "

Lets say I made a list about CSS tips and I want the background of all the list rows to be orange.

Give each area that you want to be orange a class= " ".

<ul>
<li class= "CSS-list-background"> Be creative </li>
<li class= "CSS-list-background"> Make it colorful </li>
<li class= "CSS-list-background"> Tell the browser which colors you want. </li>
</ul>

Put the class name in . format in the style tags and use the exact same rule.

.CSS-list-background {

background-color: orange;

}

CSS tips - background orange

  • Be creative
  • Make it colorful
  • Tell the browser which colors you want.

You can make the rows' color orange. Just follow the exact same format, changing "background-color" to just "color"

You will have to also change the class name, or else it would follow the same commands for both, background color and color. So you want one tag for the background color, and the color.

<ul>
<li class= "CSS-list-color"> Be creative </li>
<li class= "CSS-list-color"> Make it colorful </li>
<li class= "CSS-list-color"> Tell the browser which colors you want. </li>
</ul>

.CSS-list-color {

color: orange;

}

CSS tips - color orange

  • Be creative
  • Make it colorful
  • Tell the browser which colors you want.

So you're probably wondering, what's the difference between id and class? Didn't we do the exact same thing for both? Well...

An ID name must only be used by one HTML element within the page.
A Class name can be used by multiple HTML elements.



Recap:

To change color

text or area {

color: your color;

}

To change background

text or area {

background-color: your color;

}

id's:

#name of id {

background-color or color: your color;

}

Classes:

.name of class {

background-color or color: your color;

}

Fonts

The website probably looks boring with the same font everywhere. That's why in CSS, you can change the fonts of texts!


To change the font of a text:

Chosen text of website (h2, body, p) {

font-family: font of your choice;

}


Let's say you want to make the whole website the "Sans Serif" font.




body {

font-family: sans-serif;

}

Now you can see that the whole webiste is in the font of "Sans Serif". We did this by telling the browser to change the font of the body to "Sans Serif". We did this inside the style tags.



You're probably wondering, can we change the font of certain texts? Like we did with colors and background colors? Yes! We can.


Remember id's? We use the same exact technique here to change a certain text's font.

Jump to id's

We learned how to change the style and aesthetics of a text. In CSS, you can also change the size of a text.


To change the font size of a text


Chosen text of website (h2, body, p) {

font-size: font size of your choice(em);

}

With font sizes in CSS, we usually use the unit "em" or "px" for sizes. So lets say I want to make the paragraphs a different size.


p {

font-size: 18px;

}

Now you can see that all the paragraphs on the website are a bit bigger now.
